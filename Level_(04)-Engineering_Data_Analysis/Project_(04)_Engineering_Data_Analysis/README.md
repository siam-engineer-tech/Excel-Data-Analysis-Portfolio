
# Pump Performance Engineering Analysis Using Excel

## Project Overview

This project presents an engineering data analysis of an industrial pump performance dataset using Microsoft Excel. The objective is to transform raw operational data into meaningful engineering insights through statistical analysis, relationship analysis, predictive modeling, forecasting, and engineering calculations.

The project demonstrates how Excel can be applied as an engineering decision-support tool for evaluating equipment performance, identifying operational trends, estimating future performance, and assessing efficiency and measurement reliability.

## Objectives

The main objectives of this project are to:

- Analyze pump operating and performance data
- Understand the statistical distribution of engineering variables
- Identify relationships between operating parameters
- Develop a regression-based prediction model
- Analyze performance trends and moving averages
- Forecast future operating performance
- Evaluate different operating conditions using What-If Analysis
- Calculate pump efficiency and energy consumption
- Estimate operational and energy costs
- Evaluate measurement error and percentage error
- Perform engineering tolerance checks
- Develop an Excel-based performance dashboard

## Analysis Performed

### 1. Descriptive Statistical Analysis

The dataset was analyzed using:

- Mean
- Median
- Mode
- Minimum and Maximum
- Range
- Standard Deviation
- Variance

### 2. Percentile Analysis

Percentile analysis was performed to identify:

- 25th percentile
- 50th percentile
- 75th percentile
- 90th percentile
- Normal operating range
- High-performance operating range

### 3. Correlation Analysis

Correlation analysis was used to investigate relationships between engineering variables, including:

- Flow Rate vs Output Power
- Temperature vs Power Input
- Operating Hours vs Maintenance Cost

The strength and direction of each relationship were interpreted.

### 4. Regression and Prediction

A linear regression model was developed to investigate the relationship between Flow Rate and Output Power.

The analysis includes:

- Regression equation
- Slope
- Intercept
- R²
- Engineering predictions at selected flow rates

### 5. Trend and Forecasting Analysis

Performance trends were evaluated using:

- Line charts
- Moving averages
- Historical trend analysis
- Excel forecasting

Future operating performance was estimated based on historical observations.

### 6. What-If Analysis

Excel's decision-support tools were used to evaluate alternative operating conditions:

- Goal Seek
- Scenario Manager

These analyses were used to determine the operating conditions required to achieve a desired performance target and compare low, normal, and high operating scenarios.
